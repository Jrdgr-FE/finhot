# Privacy notice

English translation of the published Chinese privacy notice, version 1.2, effective 8 October 2026, with an explanation of the English translation feature. The Chinese version remains the reference text.

Operator: the FinHot maintainer. Contact: the on-site feedback page, /feedback.

## Browsing and hosting

No registration is required. FinHot does not set advertising trackers or proactively send visitors' browsing activity to a model. Cloudflare serves pages, public APIs and their published data. A server rented by the maintainer collects and processes public information and actively synchronizes public results. Readers do not need to contact that processing server. Hosting providers may process IP addresses, request details and technical logs to deliver and protect their services, subject to their own policies and service settings.

Application logs help diagnose technical problems and do not intentionally record feedback text, access passwords or model keys. When you leave FinHot for an original source or FinMap, that destination's notice applies. The language preference is saved in your browser so the site can remember your selection; you can change it with the language button.

## Feedback

Cloudflare stores the issue description, optional contact information, submission time and reference number you provide so the maintainer can handle and reply to the report. Feedback is private, is not sent to the summary model and is not synchronized to the processing server. Online feedback records are kept for 30 days and then removed by a scheduled task. To request earlier deletion, submit another report with the original reference number and verification information.

To limit abusive submissions, the application hashes the network address with a server-side secret and an hourly value. It stores the hash and a short-lived counter, rather than the raw IP address in the feedback database. Expired counters are removed by scheduled cleanup.

The processing server's information database is backed up daily. Backups are kept for seven days for recovery by the maintainer. Cloudflare's recovery records may remain under its own retention rules; deleting an online record does not immediately delete every provider backup. Expiry cleanup is run again after database recovery.

## Public information and models

Public titles, source material, source names and relevant context may be sent to the currently configured DeepSeek model through Command Code Provider API for summaries, classification, selection and reports. The English feature also translates public titles and summaries using that configured model. PDFs or long documents may be processed as selected pages or excerpts, with the material scope shown on the page. The model provider's own privacy policy applies.

Public information and processing records are stored on the server for the reading index and correction history. A database migration does not automatically remove existing records. Changes to retention will be described in this notice. The 30-day retention of online feedback is separate from public information records.

## Updates

This notice will be updated when account, analytics or upload features are added, or the purpose of processing changes. Do not include passwords, identity documents or unrelated personal information in feedback.
