
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 文件与规则名称 / 产品名 / 交易标的。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是公告编号 / 代号 / 没信息量的 teaser（如 "Notice"、"重磅！"、"刚刚，央行出手了"、"突发"）时，结合【来源】和正文把主体补进标题。例：原标题 "通知" + 来源与正文明确是证监会修订《上市公司信息披露管理办法》 → "证监会修订《上市公司信息披露管理办法》"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体机构时，用上位词（如"某城商行"、"某头部券商"）兜底，绝不凭"行业常识"编一个机构名 / 文号 / 金额 / 期限。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / 解读 / 盘点这类解释、分析或综述标题，中文标题必须保留这个类型；不能因为正文谈到一份已经存在的规则、一家已经存在的机构或一个已经公布的数据，就改写成“发布 / 出台 / 获批 / 开业 / 处罚”。只有原标题明确宣布了发布、出台、获批、开业或处罚，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、文件与产品名。
   例：原标题 "How banks are repricing deposits" → "银行如何重新定价存款"，不能写成 "某行上调存款利率"。
   例：原标题 "解读：注册制下 IPO 定价的变化" + 来源和正文明确是中信证券研究 → "中信证券解读注册制下 IPO 定价的变化"，不能只写成缺主体的 "注册制下 IPO 定价的变化"。
