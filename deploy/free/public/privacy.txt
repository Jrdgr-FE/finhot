# 隐私说明

版本：1.2，2026-10-08 生效。本次随服务器迁移更新托管说明。

维护署名：FinHot 维护者。联系渠道：站内反馈页 /feedback。

## 浏览与托管

本站不要求注册，不设置广告追踪，不主动将访客浏览信息发送给模型。页面、公开接口及其发布数据由 Cloudflare 提供；维护者租用的服务器负责采集、处理和主动同步公开结果。读者浏览无需访问处理服务器。服务商为交付与保护网络服务，可能处理 IP 地址、请求信息和技术日志，其平台处理规则及保留期限适用各自的政策与服务设置。

网站应用日志用于排查技术故障，不主动记录反馈正文、访问密码或模型密钥。离开本站访问原文或 FinMap 后，适用目标网站的说明。

## 反馈

本站在 Cloudflare 数据库保存你提交的问题说明、自愿填写的联系方式、提交时间和编号，供维护者处理与回复。反馈不公开，不发送给摘要模型，不同步到处理服务器。在线反馈记录保存 30 天，过期后由定时任务删除；如需提前删除，可再次提交并提供原反馈编号及核验信息。

为限制恶意提交，应用按小时对网络地址和服务端密钥计算哈希标识，只保存标识与短期计数，不将原始 IP 写入反馈数据库。计数键过期后由定时任务清理。

处理服务器上的资讯数据库每天备份，备份保存 7 天，仅供维护者恢复故障。Cloudflare 数据库的服务商恢复记录可能按其平台规则继续保留；在线删除不等于立即从服务商恢复记录中移除。恢复数据库后会重新执行在线过期清理。

## 公开资讯与模型

公开资讯的标题、正文材料、来源名称和处理所需上下文可能发送给 Command Code Provider API 当前配置的 DeepSeek 模型，用于摘要、分类、精选和日报。PDF 或较长资料可能只读取部分页或截取文本，页面保留相关材料范围提示。模型服务商适用其自身隐私政策。

公开资讯和处理记录保存于服务器，用于阅读索引及纠错追溯。数据库迁移不会自动清除已有记录；若调整保存期限，维护者会更新本说明。反馈的 30 天在线保存期限独立于资讯记录。

## 更新

新增账户、统计、上传功能或改变资料用途时，将更新本说明。请勿在反馈中提交密码、证件号码或无关个人资料。
